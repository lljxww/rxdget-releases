# RXDGET

RXDGET 是一款在本机保存资料的按揭文档工具，支持 Windows 和 macOS。

## 安装与运行

- Windows：解压 ZIP 后运行 `rxdget.exe`。
- macOS：打开 DMG，将 `RXDGET.app` 复制到本机可写的应用目录后运行。请按设备选择 Apple Silicon 或 Intel 版本。
- 首次使用时，根据引导设置工作目录、审批人员、机构信息和业务参数。业务资料与软件安装位置分开保存，升级程序会继续使用当前数据目录。
- 配套空白模板嵌入程序；导出或安装模板时保留已有文件。自定义模板需由使用者检查内容与适用范围。

## 软件更新

公开下载地址：https://github.com/lljxww/rxdget-releases/releases

程序会在后台检查正式版，也可以在“使用指南与关于 → 软件更新”手动检查。下载完成并通过校验后，选择“安装并重启”。安装前请保存编辑并等待正在执行的任务完成；程序会备份数据库，更新后继续使用原来的资料目录。

程序目录需要可写，macOS 应先将应用移出 DMG。业务功能可离线使用，网络不可用时仍可继续办理本机业务。

输出资料前，请核对机构信息、当前业务规则、模板固定文字和填写内容，并在目标办公软件中检查重算及打印效果。
